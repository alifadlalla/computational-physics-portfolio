# Photometry of 1999 TD10

In this project I used astronomical images to follow 1999 TD10 and a reference star, measure brightness and fit a light curve. [My report](report.pdf) describes the method and results.

`code/` contains the processing script, plotting notebook and saved measurement tables. The FITS images were supplied for the course. They remain in my local folder; the plotting notebook can use the small tables included here.

Install `requirements.txt` and open the notebook from `code/`.
