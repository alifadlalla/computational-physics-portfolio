# Airfoil prototype

This was a Python class project on flow around an airfoil. I used Lorena Barba's CFD with Python lesson as a reference for the flow calculation.

[My report](report.pdf) describes the work, including the airfoil-influence function that did not work and was left out.

`main.py` reads `config.yaml` and uses `airfoil_solver.py`. The saved figure is in `airfoil_simulation.pdf`, and an earlier version is in `earlier-work/`. Python packages are listed in `requirements.txt`.
