# Saturn's satellites

I completed this gravitational astrophysics project as group work. We simulated Mimas, Tethys and Titan, then studied mutual perturbations, Saturn's flattening and orbital resonances.

The code, written discussion and saved figures are together in [the report notebook](report.ipynb). `utils/convert.py` contains the orbital conversion routines provided for the course.

Install `requirements.txt` and open Jupyter from this folder. The notebook uses `%matplotlib widget` for interactive plots; saved figures are also included.

`earlier-work/` contains other scripts I saved before the final notebook.
