# Machine-learning exercises

I kept my perceptron and k-means attempts here. Some are incomplete. The k-means code started from David Cornu's teaching files; the author headers are kept, and the supplied solution is in `kmeans/provided/`.

`provided/` contains the OR-gate and PIMA examples given for the course. The Iris table and the small k-means data files are included. The PIMA table and an `iris_dataset.csv` referenced by one cell are not included.

The notebooks use NumPy, pandas, Matplotlib and scikit-learn. The saved k-means attempt has Fortran syntax errors and is kept as an unfinished exercise.
