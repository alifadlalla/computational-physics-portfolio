# Ab-initio coursework

These are notebooks and small result tables I used for atomic models and VASP exercises. The folders cover hydrogen energy curves, iron convergence and water-volume calculations. Some came from group work.

`provided/` contains the Hartree-Fock helium example and volume-fitting script given for the course. `vasp-inputs/` contains the saved INCAR, POSCAR, KPOINTS and result tables for the iron and nitrogen cases. The other folders contain my saved notebooks and analysis files. Running the input files needs a VASP installation and its pseudopotentials.

Open each notebook from its own folder. Most use NumPy, SciPy and Matplotlib. These are the saved calculations, including earlier attempts.
